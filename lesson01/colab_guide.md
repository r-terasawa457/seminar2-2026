# Colab で第1回のノートブックを動かす

第1回の実践は、Google Colaboratory（Colab）でノートブック `01_image_classification.ipynb` を動かします。Colab は Google が提供するサービスで、ブラウザから GPU 付きのノートブックを無料で使えます。

- Colab で GPU が使えないときは、Kaggle で同じ実践ができます（`kaggle_guide.md`）。
- 内容は 2026年11月時点のものです。Colab の画面の名前や制限は変わることがあります。違っていたら、近い名前のものを探してください。

## 1. Google アカウントを用意する

Colab を使うには Google アカウントが必要です。持っていなければ、<https://accounts.google.com/signup> で作ります。

- 大学などの組織のアカウント（Google Workspace）では、管理者が Colab を使えない設定にしていることがあります。開けないときは、個人の Google アカウントを使ってください。
- 作ったノートブックは、そのアカウントの Google ドライブに保存されます。

## 2. ノートブックを開いて、自分のコピーを作る

1. 次の URL をブラウザで開きます。GitHub のノートブックが Colab で開きます。
   `https://colab.research.google.com/github/r-terasawa457/seminar2-2026/blob/main/lesson01/01_image_classification.ipynb`
   - 開けないときは、<https://colab.research.google.com> の **ファイル** → **ノートブックを開く** → **GitHub** の欄に `r-terasawa457/seminar2-2026` と入れ、`lesson01/01_image_classification.ipynb` を選びます。
2. 右上で Google アカウントにログインします（ログインしていないと実行できません）。
3. **ファイル** → **ドライブにコピーを保存**（上のツールバーの **ドライブにコピー** でも同じ）を選びます。新しいタブで自分のコピーが開きます。
4. **以後は、このコピーで作業します。** GitHub から開いたままのノートブックは保存されません。コピーは Google ドライブの「Colab Notebooks」フォルダに入り、次からはドライブ、または **ファイル** → **ノートブックを開く** から開けます。

## 3. GPU を選ぶ

1. **ランタイム** → **ランタイムのタイプを変更** を選びます。
2. **ハードウェア アクセラレータ** で **T4 GPU** を選び、**保存** を押します。

選べる GPU の種類は、時期や混み具合で変わります。無料で選べるのは、ふつう T4 GPU です（ほかの GPU は有料プランの人向け）。

## 4. 実行する

上のセルから順に実行します（セルを選んで **Shift + Enter**、またはセルの左の再生ボタン）。**ランタイム** → **すべてのセルを実行** で全部を実行することもできますが、最初は1つずつ、出力を見ながら進めてください。

- 最初に実行したときに、ノートブックが Google の作成したものではない、という警告が出たら、**このまま実行** を押します（このノートブックは、セミナーのリポジトリのものです）。
- 1. の最初のセルでリポジトリを取得し、作業フォルダが `/content/seminar2-2026/lesson01` になれば成功です。次のセルで次のように表示されれば、GPU で計算しています。

```
device: cuda Tesla T4
```

`device: cpu` と表示されたら、3. で GPU を選び直してください。GPU を選べない（使用量の上限に達した、という表示が出る）ときは、Kaggle を使います（`kaggle_guide.md`）。CPU のままでも動きますが、枚数を減らしても時間がかかります。

## 5. 使える時間と、終わったときの操作

無料の Colab は、リソースが保証されません。使える GPU の時間や種類は、混み具合や使い方によって変わり、上限の値は公開されていません。

| 項目 | 内容 |
| --- | --- |
| 1回の接続 | 最長12時間（混み具合によっては短くなる） |
| 操作しないとき | しばらく操作しないと、接続が切れる |
| GPU を使える量 | 決まった値は公開されていない。使いすぎると、しばらく GPU を選べなくなる |

このノートブックは、本編と 9. の実験を合わせても、GPU で1〜2時間あれば終わります。

**終わったら、ランタイムを止めてください。** **ランタイム** → **ランタイムを接続解除して削除** を選びます。GPU を使ったまま放っておくと、使用量が増え、次に GPU を選べなくなることがあります。

接続が切れたり、ランタイムを削除したりすると、変数、学習したモデル、取得したファイルが消えます。ドライブのコピーに残るのは、ノートブックの文章、コード、出力です。再開するときは、1. から順に実行し直してください（[確かめよう] は飛ばしてかまいません）。

## 6. 保存とダウンロード

- ドライブのコピーは自動で保存されます。すぐに保存したいときは **ファイル** → **保存**（Ctrl + S）。
- 手元に保存するときは、**ファイル** → **ダウンロード** → **.ipynb をダウンロード** を選びます。

### 課題（10.）の PDF を作る

1. 出力（グラフや表）が表示された状態で、**ファイル** → **印刷**（Ctrl + P）を選びます。
2. 送信先を「PDF に保存」にして保存します。

画像や表が途中で切れるときは、印刷の画面で用紙を横向きにするか、拡大縮小の倍率を下げてください。

## 7. 自分の画像を使う（8-2 と、10. の発展）

### 8-2：自分の画像で推論する

8-2 のセルで `USE_UPLOAD = True` にして実行すると、**ファイルを選択** のボタンが表示されます。画像（jpg、png など）を選ぶと、アップロードされ、1枚ずつ予測します。複数の画像をまとめて選べます。

### 10. の発展：自分の画像で学習する

クラスごとにフォルダを分けた画像（例：`my_images/cat/`、`my_images/dog/`）を、zip にまとめてから使います。

1. 手元で `my_images` フォルダを zip にします（`my_images.zip`）。
2. 左の **ファイル**（フォルダのアイコン）を開き、アップロードのボタンで `my_images.zip` を上げます。作業フォルダ（`seminar2-2026/lesson01`）の中に置くか、上げたあとでドラッグして移します。
3. セルで次を実行して展開します。
   ```
   !unzip -q my_images.zip
   ```
4. 2. で `IMAGE_DIR = "my_images"` にして、最初から実行します。

アップロードしたファイルも、ランタイムを削除すると消えます。何度も使うときは、Google ドライブに置いて、左の **ファイル** の **ドライブをマウント** のボタンで読む方法もあります（ドライブのファイルは `/content/drive/MyDrive/` の下に見えます）。

## 8. Kaggle との違い

| | Colab | Kaggle |
| --- | --- | --- |
| ノートブック | `01_image_classification.ipynb` | `01_image_classification_kaggle.ipynb` |
| アカウント | Google アカウント | Kaggle のアカウント（電話番号の認証が必要） |
| GPU の選び方 | ランタイム → ランタイムのタイプを変更 → T4 GPU | Session options → Accelerator → GPU T4 x2 |
| GPU を使える量 | 公開されていない（混み具合で変わる） | 1週間に約30時間 |
| 作業フォルダ | `/content` | `/kaggle/working` |
| 保存 | ドライブにコピーを保存 | 下書きの自動保存、Save Version |

## 9. 困ったとき

| 症状 | 原因と対処 |
| --- | --- |
| ノートブックが開けない、「アクセスできません」と出る | 組織のアカウントで Colab が止められている。個人の Google アカウントで開く（1.） |
| 書き換えたのに、開き直したら元に戻っている | GitHub から開いたノートブックで作業していた。ドライブにコピーを保存して、コピーで作業する（2.） |
| T4 GPU を選べない、使用量の上限の表示が出る | 無料の GPU の上限に達した。時間をおいて試すか、Kaggle を使う（`kaggle_guide.md`） |
| `device: cpu` と表示される | GPU を選んでいない（3.） |
| `NameError`（名前が定義されていない） | 前のセルを実行していないか、接続が切れた。1. から順に実行し直す |
| 実行中に「接続が切れました」と出た | 操作しない時間が続いたか、上限の時間を超えた。再接続して、1. から順に実行し直す |
| `CUDA out of memory` | 9. で大きなモデルや大きな batch サイズを選んだ。`batch_size` を小さくする。それでも出るときは、**ランタイム** → **セッションを再起動する** で再起動して、1. からやり直す |
| 8-2 でボタンが表示されない、図が表示されない | ブラウザがサードパーティの Cookie を止めていることがある。ブラウザの設定で `googleusercontent.com` を許可する（Colab のよくある質問） |

それでも解決しないときは、エラーの最後の数行と、どのセルで出たかを添えて質問してください。
